# A Peça que Faltava

Motor de vídeos animados (bonecos 2D com volume, câmera de cinema, vozes em português) e rotina diária do canal.

- `engine/` — motor (`make.py roteiro.json pasta`)
- `stories/` — roteiros publicados
- `ROTINA.md` — passo a passo da produção diária
- `historico.json` — temas já publicados
- `DIARIO.md` — registro de cada execução
- Vídeos ficam em **Releases** (um por episódio)
